# 🍜 ラーメン推薦アプリ

現在地で評判の良いラーメン屋を探し、詳しい解説付きで推薦してくれるWebアプリケーションです。

## 機能

- 📍 **位置情報の取得**: ブラウザの位置情報機能を使用して、現在地を自動取得
- 🔍 **周辺検索**: 現在地から2km圏内のラーメン屋を検索
- ⭐ **評価表示**: 各店舗の評価とレビュー数を表示
- 📝 **詳細説明**: 各ラーメン屋の特徴や魅力を解説
- 🚶 **距離・時間表示**: 現在地からの距離と徒歩時間を計算
- 🏷️ **タグ機能**: 店舗の特徴をタグで表示（深夜営業、個室あり、など）
- 🗺️ **Google Mapsリンク**: 各店舗のGoogle Mapsページを直接開ける
- 📱 **レスポンシブデザイン**: スマートフォンでも快適に利用可能

## 使い方

1. ブラウザで `index.html` を開く
2. 「📍 現在地を取得」ボタンをクリック
3. ブラウザの位置情報使用許可を承認
4. 周辺のおすすめラーメン屋が評価順に表示されます

## 主な実装機能

### 位置情報取得

ブラウザの `navigator.geolocation` APIを使用して、ユーザーの現在位置を取得します。位置情報の使用許可が必要です。

### データ取得

1. **Overpass API**: OpenStreetMapのデータから周辺のラーメン屋を検索
2. **フォールバック**: APIからデータが取得できない場合、サンプルデータを表示

### 表示情報

各ラーメン屋について以下の情報を表示：

- 店名
- 評価（★5段階）
- 住所
- 距離（km）
- 徒歩時間（分）
- レビュー数
- 店舗の特徴（説明文）
- タグ（深夜営業、個室あり、テイクアウト可、など）

### ソート・ランキング

評価の高い順に自動ソートされ、トップ10のラーメン屋を表示します。

## トラブルシューティング

### 位置情報が取得できない

- ブラウザの位置情報使用許可を確認
- HTTPS環境で実行しているか確認
- ブラウザの設定で位置情報サービスが有効になっているか確認

### ラーメン屋が見つからない

- 検索範囲を広げる（`radius` を増やす）
- サンプルデータが自動的に表示されます

### APIエラーが発生する

- インターネット接続を確認
- Overpass APIがダウンしている可能性（自動的にサンプルデータに切り替わります）

# 🍜 ラーメン推薦アプリ

指定した場所で評判の良いラーメン屋を探し、詳しい解説付きで推薦してくれるWebアプリケーションです。

## 機能

- 📍 **場所の指定**: 駅名、住所、地名などを入力して検索
- 🔍 **周辺検索**: 指定した場所から2km圏内のラーメン屋を検索
- ⭐ **評価表示**: 各店舗の評価とレビュー数を表示
- 📝 **詳細説明**: 各ラーメン屋の特徴や魅力を解説
- 🚶 **距離・時間表示**: 指定地点からの距離と徒歩時間を計算
- 🏷️ **タグ機能**: 店舗の特徴をタグで表示（深夜営業、個室あり、など）
- 🗺️ **Google Mapsリンク**: 各店舗のGoogle Mapsページを直接開ける
- 📱 **レスポンシブデザイン**: スマートフォンでも快適に利用可能

## 使い方

1. ブラウザで `index.html` を開く
2. 検索フォームに場所を入力（例：東京駅、渋谷区、新宿三丁目）
3. 「🔍 検索」ボタンをクリック
4. 周辺のおすすめラーメン屋が評価順に表示されます

## 技術仕様

### 使用技術

- **HTML5**: セマンティックマークアップ
- **CSS3**: モダンなグラデーションとアニメーション、レスポンシブデザイン
- **Vanilla JavaScript**: フレームワーク不要、軽量な実装
- **Nominatim API**: OpenStreetMapのGeocoding（住所→座標変換）
- **Overpass API**: OpenStreetMapのデータを活用したラーメン屋検索

## 主な実装機能

### 場所の指定とGeocoding

入力された住所や地名を **Nominatim API** を使用して座標（緯度・経度）に変換します。日本国内の場所に対応しており、駅名、住所、地名などを柔軟に検索できます。

### データ取得

1. **Overpass API**: OpenStreetMapのデータから周辺のラーメン屋を検索
2. **フォールバック**: APIからデータが取得できない場合、サンプルデータを表示

### 表示情報

各ラーメン屋について以下の情報を表示：

- 店名
- 評価（★5段階）
- 住所
- 距離（km）
- 徒歩時間（分）
- レビュー数
- 店舗の特徴（説明文）
- タグ（深夜営業、個室あり、テイクアウト可、など）

### ソート・ランキング

評価の高い順に自動ソートされ、トップ10のラーメン屋を表示します。

## トラブルシューティング

### 場所が見つからない

- より具体的な場所を入力してください（例：「渋谷」より「渋谷駅」）
- 都道府県名を含めてみてください（例：「東京都 渋谷駅」）
- 郵便番号や完全な住所でも検索できます

### ラーメン屋が見つからない

- 検索範囲を広げる（`app.js`の `radius` を増やす）
- サンプルデータが自動的に表示されます

### APIエラーが発生する

- インターネット接続を確認
- Nominatim APIまたはOverpass APIがダウンしている可能性
- 少し時間を置いてから再試行してください

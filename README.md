# 🍜 ラーメン推薦アプリ

場所を指定または現在地で評判の良いラーメン屋を探し、詳しい解説付きで推薦してくれるWebアプリケーションです。

## 機能

- 📍 **2つの検索方法**:
  - 場所を入力して検索（駅名、住所、地名など）
  - 現在地から自動検索（位置情報使用）
- 🔍 **周辺検索**: 指定地点から2km圏内のラーメン屋を検索
- 🚫 **閉業店舗を除外**: 営業中の店舗のみを表示
- 📸 **ラーメン写真**: 各店舗に美味しそうなラーメンの写真を表示
- ⭐ **評価表示**: 各店舗の評価とレビュー数を表示
- 💭 **レビュー要約**: 評価に基づいたリアルなレビューコメントを表示
- 📝 **詳細説明**: 各ラーメン屋の特徴や魅力を解説
- 🚶 **距離・時間表示**: 指定地点からの距離と徒歩時間を計算
- 🏷️ **タグ機能**: 店舗の特徴をタグで表示（深夜営業、個室あり、など）
- 🗺️ **Google Mapsリンク**: 各店舗のGoogle Mapsページを直接開ける
- 📱 **レスポンシブデザイン**: スマートフォンでも快適に利用可能

## 使い方

### 方法1: 場所を指定して検索

1. ブラウザで `index.html` を開く
2. 検索フォームに場所を入力（例：東京駅、渋谷区、新宿三丁目）
3. 「🔍 検索」ボタンをクリック
4. 周辺のおすすめラーメン屋が評価順に表示されます

### 方法2: 現在地から検索

1. ブラウザで `index.html` を開く
2. 「📍 現在地から検索」ボタンをクリック
3. ブラウザの位置情報使用許可を承認
4. 現在地周辺のおすすめラーメン屋が評価順に表示されます

## 技術仕様

### 使用技術

- **HTML5**: セマンティックマークアップ
- **CSS3**: モダンなグラデーションとアニメーション、レスポンシブデザイン
- **Vanilla JavaScript**: フレームワーク不要、軽量な実装
- **Geolocation API**: ブラウザの位置情報機能（現在地検索）
- **Nominatim API**: OpenStreetMapのGeocoding（住所→座標変換）
- **Overpass API**: OpenStreetMapのデータを活用したラーメン屋検索

## 主な実装機能

### 2つの検索方法

**1. 場所を指定して検索**
入力された住所や地名を **Nominatim API** を使用して座標（緯度・経度）に変換します。日本国内の場所に対応しており、駅名、住所、地名などを柔軟に検索できます。

**2. 現在地から検索**
ブラウザの **Geolocation API** を使用してユーザーの現在位置を取得します。位置情報の使用許可が必要です。

### データ取得と閉業店舗の除外

1. **Overpass API**: OpenStreetMapのデータから周辺のラーメン屋を検索
2. **閉業店舗フィルター**: 以下の条件で閉業店舗を自動除外
   - `disused:amenity` タグがある店舗
   - `opening_hours` が "closed" の店舗
   - `lifecycle` タグが "abandoned", "disused", "demolished" の店舗
   - `abandoned` または `disused` タグが "yes" の店舗

### 表示情報

各ラーメン屋について以下の情報を表示：

- 店名
- 評価（★5段階）
- **ラーメン写真**: Unsplashの高品質な写真を表示
  - 醤油、味噌、豚骨、つけ麺など様々な種類
  - ホバー時に拡大アニメーション
  - 遅延読み込み（lazy loading）対応
- 住所
- 距離（km）
- 徒歩時間（分）
- レビュー数
- 店舗の特徴（説明文）
- **レビュー要約**: 評価に応じた3つのレビューコメント
  - 高評価店（4.5以上）：ポジティブなコメント中心
  - 中評価店（4.0以上）：ポジティブと改善点のバランス
  - 通常評価店：多様な視点のコメント
- タグ（深夜営業、個室あり、テイクアウト可、など）

### ソート・ランキング

評価の高い順に自動ソートされ、トップ10のラーメン屋を表示します。

## トラブルシューティング

### 現在地が取得できない

- ブラウザの位置情報使用許可を確認してください
- HTTPS環境で実行していることを確認してください（一部のブラウザで必要）
- ブラウザの設定で位置情報サービスが有効になっているか確認してください
- 場所を入力する検索方法もお試しください

### 場所が見つからない

- より具体的な場所を入力してください（例：「渋谷」より「渋谷駅」）
- 都道府県名を含めてみてください（例：「東京都 渋谷駅」）
- 郵便番号や完全な住所でも検索できます

### ラーメン屋が見つからない

- 検索範囲を広げる（`app.js`の `radius` を増やす）
- 別の場所や都市を検索してみてください
- OpenStreetMapにデータが登録されていない地域もあります

### APIエラーが発生する

- インターネット接続を確認
- Nominatim APIまたはOverpass APIがダウンしている可能性
- 少し時間を置いてから再試行してください
